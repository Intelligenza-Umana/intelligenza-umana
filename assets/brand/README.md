# Intelligenza Umana — Visual identity

The emblem represents human agency, mathematical reasoning and responsible technological progress.

- **Open hand:** human responsibility, action and care.
- **Vitruvian-inspired figure:** humanity at the centre of technological progress.
- **Circle and square:** mathematical reasoning, proportion and the scientific method.
- **Open outer arc:** knowledge remains open to questioning and revision.
- **Four-point star:** curiosity and the pursuit of knowledge.

These are intended symbolic interpretations, not claims about the historical meaning of the original Vitruvian drawing.

SVG files are monochrome vector traces of the selected raster concepts. Small-size legibility should be checked in the target application. The modern sans-serif wordmark is approved. Both wordmark variants use identical vector outlines with inverted colours; no external font is needed.
