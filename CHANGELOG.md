# Changelog

## 0.3.0 — 2026-11-28 — Community & Governance Update

- Established the GitHub organization as the central home for independent projects, with shared contribution and governance guidance.
- Established the public website and Discord community; documented Sentinel's moderation and owner-approved administration responsibilities.
- Introduced optional organization membership requests, including an optional numeric Discord user ID, with manual review, voluntary acceptance and separate repository permissions.
- Improved contributor onboarding, beginner-friendly issue discovery and guidance for verifiable AI-agent skill contributions.
- Replaced duplicated project catalogs with live GitHub discovery and aligned project READMEs with shared community standards.
- Recorded deferred ideas for cross-platform integrations, Telegram and future community operations without committing to implementation.
- Kept the Foundation version independent from software releases. This is an early-stage governance milestone, not a declaration of operational maturity or verified host compatibility. Live membership and integration behavior still need practical validation.
