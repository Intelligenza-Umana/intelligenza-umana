# Governance
The foundation is authoritative for identity, principles, standards, strategy and registry. Independent repositories own code, tests, releases and architecture. GitHub does not automatically inherit these rules: consult central governance and local instructions; report missing access and block work requiring unavailable context.

The founder initially retains strategic responsibility and publication approval. Future maintainers and reviewers may receive explicit responsibilities. Proposals, issues, PRs and reviews are welcome; roles and access are agreed, and no member is registered without consent.

## Human-Verified Engineering (working title)
Define the problem and requirements; study alternatives; implement with or without AI; understand and review code; run reproducible tests and checks; obtain peer review when available; publish limitations and results. Human judgment is not deterministic: automated checks complement review. Contributions lacking understanding, adequate evidence or risk mitigation must be corrected before merge. No secrets in Git. Establish private vulnerability reporting before public opening.

Currently founder-operated and open to contributions; the [GitHub organization](https://github.com/Intelligenza-Umana) has been created, and no additional maintainers are confirmed. The organization hosts independent project repositories; the live catalog and project-local evidence are described in [the registry](PROJECT_REGISTRY.md). See [community](../community/README.md). The [engineering standard](ENGINEERING_STANDARD.md) defines verification and release requirements; [SECURITY](../SECURITY.md) governs reporting. High-risk changes require independent review before stable release.

## Membership and responsibilities

Anyone can contribute to public projects without membership. Organization membership is voluntary and recognizes sustained interest in collaboration, reliability and alignment with IU principles. Relevant experience or public work outside IU may justify acceptance before a first IU contribution; there is no seniority threshold or contribution quota. Owners review applicants individually. Membership is separate from repository permissions and maintainer responsibilities, which must be explicitly assigned according to trust and need. See [onboarding](../community/ONBOARDING.md).
