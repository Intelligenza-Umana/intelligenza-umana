# Roadmap
- Foundation: maintain governance and standards; maintain the security mailbox and verify reply delivery. The tree and Markdown link paths were audited at commit 765c1de.
- Extensions: verify installation, tests, licenses, English documentation and releases for all four tools.
- Open-source readiness: CONTRIBUTING, conduct, SECURITY, PR criteria, CI and issues; configure the new GitHub organization and verify access.
- Research: real problems, alternatives, gaps, RFCs and verifiable prototypes.
- Flagship: select a validated problem, scope an MVP and enable modular contributions.
- Community: gradual collaboration based on interest and maintenance capacity.
- Web: catalog, documentation, releases and contributions.
No artificial deadlines or social media obligations. Editorial strategy retired; history remains in Git.

## Shared priorities (2026-11-26)

1. **Contributor access:** improve [onboarding](https://github.com/fabiozagaria/intelligenza-umana/issues/3); add [installer CI](https://github.com/fabiozagaria/iu-project-lifecycle-skill/issues/1) and clarify [model fallback](https://github.com/fabiozagaria/iu-model-router/issues/1). Anyone can contribute by fork and pull request.
2. **Release confidence:** verify installations, reconcile manifest and release versions, and verify private vulnerability reporting for each product. Record actual results and limitations.
3. **Organization migration:** inventory integrations and permissions for each repository, prepare a tested rollback and obtain founder approval before any transfer. Preserve existing URLs until each change is verified.
4. **Community infrastructure:** assess branch protection, Discussions and Projects with the founder; avoid mandatory checks without a reliable workflow or permission changes without approval.

The issues and pull requests are the shared work queue; priorities can change with maintainer capacity. No dates are committed.
