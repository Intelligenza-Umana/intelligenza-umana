# Why Intelligenza Umana exists

We live in a time when a machine can answer almost any question with an ease that, not long ago, seemed impossible. Artificial intelligence is fast, useful and at times surprising. It lowers barriers, makes accessible what was reserved for a few, and opens paths that were not visible before. But every powerful tool asks something in return: that whoever uses it knows what they are doing.

Since 2023, with the arrival of ChatGPT, the founder approached generative language models with wonder. Talking with them felt like a dialogue, and within that dialogue one could explore big questions about life, the universe, and what is not yet known. Above all, these tools made the study of programming more alive, and helped to stay focused.

Over time an uncomfortable truth emerged. A language model does not know in the way a person knows: it computes the most probable answer. That probability can be very high and still be wrong. Nothing solid can be built on a percentage. This is why human review is not a detail: it is what turns a plausible answer into something for which someone can take responsibility.

In software this matters even more. Programming, in its deepest sense, is reasoning: breaking a problem down, choosing one idea among many possible ones, turning it into bits and algorithms, and writing code that another human being can read and understand. Code can be generated, but understanding and verifying it remains a human act. A program that no one understands is a program that no one can truly govern.

The project is concretely born from a desire: to spread the idea that code can be generated with artificial intelligence, but with review and awareness.

Intelligenza Umana is born from this conviction: artificial intelligence can amplify thought, but thought must remain human.
