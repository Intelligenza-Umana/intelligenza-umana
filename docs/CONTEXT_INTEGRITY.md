# Context Integrity Protocol
Mandatory before and after each change. 1. Inventory structure, instructions, Git state and map; read relevant sources. 2. Verify actual state and conflicts; block if essential context is missing. 3. Identify impact on files, documents, dependencies and satellites; propose structural changes. 4. Implement and update obsolete sources; verify unchanged sources without rewriting. 5. Check diffs, links, tests, decisions, roadmap, map and registry. 6. Update handoff after significant sessions with changed sources, verified unchanged sources, discrepancies, blockers and next step. Periodic audits on request; no implicit fixes. Never claim completion without evidence. Derived from skill v0.2.0.
