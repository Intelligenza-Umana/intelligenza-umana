# Definition of Done
- [ ] Contesto, stato reale e impatto verificati
- [ ] Risultato e test pertinenti verificati
- [ ] Fonti impattate aggiornate o motivate come invariate
- [ ] Decisioni, roadmap, registro e mappa verificati
- [ ] Diff, link e contraddizioni controllati
- [ ] Handoff aggiornato se sessione significativa
- [ ] Blocchi e verifiche mancanti dichiarati
- [ ] Commit/push solo se autorizzato
