# Security policy

Do not disclose exploitable vulnerabilities, secrets or personal data in public issues. Report vulnerabilities privately to [intelligenzaumana.lab@gmail.com](mailto:intelligenzaumana.lab@gmail.com), or use GitHub private vulnerability reporting where enabled in the affected repository. Include affected versions, impact and safe reproduction steps in private reports. Avoid testing against systems without authorization.

This is a shared general-purpose mailbox, not a dedicated security mailbox. No response SLA has been established. The founder reports that the mailbox has been created; delivery and receipt have not yet been verified. Each software repository must define supported versions and a verified reporting channel before public release.
