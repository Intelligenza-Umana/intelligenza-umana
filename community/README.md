# Community IU
Community tecnica open source in preparazione, non ancora operativa. Collaborazione tramite issue, proposte, pull request e peer review. Apertura graduale sulla base di progetti utili e capacità di manutenzione. Nessun requisito di seniority; comprensione, evidenze e rispetto obbligatori. Nessuna associazione giuridica o rapporto di lavoro. I documenti precedenti su reclutamento e social sono sospesi ove incompatibili con la governance v0.2.0.
