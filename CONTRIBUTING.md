# Contributing
Contributions are welcome when repositories are opened for collaboration. Start with an issue describing the problem, evidence and expected outcome. Discuss architectural changes through an RFC before coding. AI assistance is allowed; contributors must understand and take responsibility for their changes. Include relevant tests, reproduction steps, security and data-integrity considerations, limitations and material AI assistance. Maintainers may request changes or reject unverified work. No seniority requirement. See community/CONTRIBUTING.md and docs/DEFINITION_OF_DONE.md.
