# Pipeline
Tema → ricerca → script → storyboard → asset → voce umana o sintetica verificata → montaggio programmatico → sottotitoli → QA umano → export → approvazione pubblicazione. Conservare fonti, versioni, licenze asset e risultati; file pesanti con riferimenti GitHub.

Il tema proviene dal backlog approvato di [automazione editoriale](EDITORIAL_AUTOMATION.md); video successivi all'MVP di ricerca e revisione.
